# KheeHubb

KheeHubb is an Android application designed to help users locate and manage public toilets. It features an interactive map powered by Google Maps, real-time data storage via Firebase Firestore, and user-friendly tools for searching, filtering, and adding toilet locations.

## Features

- **Interactive Map**: View toilet locations on a Google Map with markers indicating availability and opening hours.
- **Search Functionality**: Search for toilets by name or floor.
- **Filters**: Filter toilets by tags (e.g., accessibility features) or show only currently open ones.
- **Find Nearest Toilet**: Use GPS to locate the closest available toilet based on filters.
- **Add/Edit Toilets**: Contribute new toilet data or update existing entries with details like rating, floor, and tags.
- **Real-Time Data**: All toilet information is stored and synced via Firebase Firestore.

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/ziqiqiiii/KheeHub.git
   cd KheeHub
   ```

2. Open the project in Android Studio.

3. Set up API keys:
   - Obtain a Google Maps API key from the [Google Cloud Console](https://console.cloud.google.com/).
   - Add the key to `gradle.properties`:
     ```
     MAPS_API_KEY=your_api_key_here
     ```
   - Ensure `local.properties` has your SDK path (auto-generated by Android Studio).

4. Configure Firebase:
   - Create a Firebase project at [Firebase Console](https://console.firebase.google.com/).
   - Download `google-services.json` and place it in `app/`.
   - Enable Firestore in your Firebase project.

5. Build and run the app on an Android device or emulator (min SDK 24).

## Usage

- **Navigation**: Use the bottom navigation to switch between Map, Add, and Settings.
- **Map View**: Tap markers for details, use search or filters.
- **Adding Toilets**: Fill in the form in the Add tab and submit.
- **Permissions**: Grant location and internet permissions for full functionality.

## Architecture

- **Language**: Java
- **Framework**: Android SDK with Fragments and Material Design
- **Data Storage**: Firebase Firestore
- **Mapping**: Google Maps SDK
- **Key Classes**:
  - `MainActivity`: Handles navigation between fragments.
  - `MapFragment`: Displays the map, markers, search, and filters.
  - `AddFragment`: Form for adding new toilets.
  - `ToiletRepository`: Manages Firestore operations (singleton pattern).
  - `Toilet`: Data model for toilet information.

## Dependencies

- Google Maps: `com.google.android.gms:play-services-maps:19.0.0`
- Firebase: `com.google.firebase:firebase-firestore` (via BoM 34.11.0)
- Location Services: `com.google.android.gms:play-services-location:21.0.1`
- Material Components: `com.google.android.material:material:1.12.0`
- AndroidX Libraries: AppCompat, Activity, ConstraintLayout, etc.
